## 1. Prompt Layer Architecture

The NextLite prompt engine strictly separates universal runtime behavioral rules from template/industry content and dynamic call context.

```
┌───────────────────────────────────────────────────────────┐
│ 1. UNIVERSAL RUNTIME SAFETY & BEHAVIOR RULES (Authoritative)│
│    - Anti-hallucination policy                            │
│    - Telephone conversational conciseness (1-2 sentences)  │
│    - UUID speech suppression rule                         │

├───────────────────────────────────────────────────────────┤
```

## 2. Universal Runtime Rules (Invariable Core)

1. **Conciseness on PSTN:** "You are a real-time telephone voice agent. Keep answers natural, concise (1-2 sentences maximum per turn), and conversational. Do not output markdown, bullet points, asterisks, or formatting."
2. **Anti-Hallucination:** "Never invent available appointment slots, services, or prices. Always call `query_knowledge_base` or `book_appointment` before confirming facts."
3. **UUID Suppression:** "Never read out raw system IDs or UUIDs. Only speak customer-safe appointment numbers (e.g. APT-1002)."
4. **Tool Confirmation:** "When booking an appointment or capturing a lead, always verbally confirm the date, time, and service with the caller."
5. **Digit Pronunciation:** "Read phone numbers and reference numbers digit by digit clearly."

## 3. Multilingual Engine (`language_manager.py`)

### Supported Locales:
- `en-IN` (Indian English)
- `hi-IN` (Hindi)
- `mr-IN` (Marathi)
- `hinglish` (Hindi-English colloquial code-switching)
- `minglish` (Marathi-English colloquial code-switching)

### Rules & Mechanisms:
1. **Initial State:** Worker begins with `RuntimeAgentConfig.language.primary`.
2. **STT Language Hinting:** If Sarvam STT supports multilingual transcription, it transcribes input phonetically and semantically.
3. **Code-Switching Detection:** If caller initiates in Hindi or Marathi, `LanguageManager.detect_and_switch()` updates the session state.
4. **TTS Voice Synchronization:** Bulbul v3 dynamically adapts to Devanagari script output generated by Sarvam LLM.
