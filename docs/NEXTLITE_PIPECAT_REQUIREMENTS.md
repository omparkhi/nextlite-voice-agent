# NextLite Voice V3 — Final Pipecat Migration Requirements (Phase 6+)

> **Scope**: Strict Categorized Requirements for Completing LiveKit &rarr; Pipecat Migration  
> **Status**: Requirements Specification Only (NO CODE IMPLEMENTATION)  
> **Timestamp**: 2026-09-09  

---

## 1. MUST PRESERVE EXACTLY (Zero Changes Permitted)

1. **`RuntimeAgentConfig` Schema & DTO Contract**: Must preserve the exact interface in `packages/shared/src/runtimeConfig.ts`.
2. **`PromptCompilerService` Output**: Must preserve the exact multi-section compiled prompt output (Layer A + Layer B).
3. **Database Schema & Migrations**: All 15 PostgreSQL tables, enums, indices, and constraints in `apps/api/src/db/schema.ts`.
4. **Internal Worker REST Endpoints**: Must preserve paths, headers, and schemas for `/api/internal/*`.
5. **Sequential Appointment Numbering**: Must preserve the `A-001` format generated by `tenant_appointment_counters`.
6. **UUID Suppression Rule**: Must preserve the rule that database UUIDs are never spoken to callers.
7. **CRM Data Models**: All `CallSession`, `Lead`, `Appointment`, and `FollowUp` schemas.
8. **Client Dashboard & Admin Studio**: All React frontend pages, components, and workflows.

---

## 2. MUST REUSE THROUGH API (Worker Must Consume via HTTP REST)

1. **`GET /api/internal/runtime-config/:deploymentId`**: Pipecat worker must call this endpoint upon call connection to resolve runtime configuration.
2. **`POST /api/internal/knowledge/retrieve`**: Pipecat tool `query_knowledge_base` must call this endpoint for RAG vector search.
3. **`POST /api/internal/appointments`**: Pipecat tool `book_appointment` must call this endpoint to record appointment requests.
4. **`POST /api/internal/leads`**: Pipecat tool `create_callback_lead` must call this endpoint to record callback leads.
5. **`POST /api/internal/call-sessions`**: Pipecat worker must call this endpoint on stream start to create `ACTIVE` call sessions.
6. **`PATCH /api/internal/call-sessions/:id`**: Pipecat worker must call this endpoint on stream termination to finalize session state, duration, turns, and metrics.
7. **`GET /api/internal/phone-numbers/lookup`**: Telephony ingress must call this endpoint to resolve `deploymentId` from the dialed DID.

---

## 3. MUST PORT TO PIPECAT (Python Worker Implementation in Phase 6+)

1. **HTTP Client (`runtime_config_client.py`)**: Async HTTP client (`aiohttp` or `httpx`) calling `/api/internal/*` with `WORKER_API_SECRET`.
2. **Multilingual Language Manager (`language_manager.py`)**: Porting `ConversationLanguageManager`, the 12 Indic explicit regex patterns, and Latin Hinglish/Minglish marker filters.
3. **Temporal Context Generator (`temporal_context.py`)**: Generating current date, time, and timezone instructions.
4. **Calendar Context Generator (`calendar_context.py`)**: Generating the 7-day relative calendar matrix.
5. **Native Tool Registry (`tools/`)**: Registering `query_knowledge_base`, `book_appointment`, and `create_callback_lead` as native Pipecat function tools.
6. **Turn & Debug Transcript Collector (`debug_transcript.py`)**: In-memory message and tool accumulator for generating plain text transcripts on call finalization.
7. **Dynamic Voice Configuration Wiring**: Binding `RuntimeAgentConfig.voice.voiceId`, `voice.sttModel`, `voice.ttsModel`, and `runtime.llmModel` dynamically into the Pipecat pipeline on each call.

---

## 4. MUST NOT PORT (LiveKit Specifics to Discard)

1. **`@livekit/agents` & `livekit-server-sdk`**: Discard all LiveKit server connections, tokens, rooms, and agent runners.
2. **LiveKit SIP Gateway Configuration**: Discard SIP trunk ID routing in worker; replace with direct Plivo WebSocket stream.
3. **`@livekit/rtc-node` WebRTC Codecs**: Discard 48kHz WebRTC audio track encoding.
4. **`inference.TurnDetector(v1-mini)`**: Discard LiveKit-specific turn detector; use native Sarvam STT VAD event signals.

---

## 5. MUST NOT DUPLICATE (Control Plane Owned)

1. **Do NOT build a database connection layer in Python.**
2. **Do NOT build vector search or embedding generation in Python.**
3. **Do NOT build a prompt compiler in Python.**
4. **Do NOT build appointment counter sequencing in Python.**
5. **Do NOT build WhatsApp messaging in Python.**

---

## 6. MUST BE REFACTORED / PREPARED BEFORE PHASE 6

1. **Remove Hardcoded `TEST_PROMPT` in `config.py`**: Must be replaced with dynamic resolution of `compiledSystemPrompt`.
2. **Remove Hardcoded `PHASE2_TEST_VOICE_ID`**: Must be replaced with dynamic resolution of `voiceId`.
3. **Inbound Telephony Routing Webhook**: Provide a Plivo Answer XML webhook endpoint in `apps/api` that looks up dialed phone numbers via `phoneNumberService` and returns the dynamic WebSocket stream URL with `deploymentId`.

---

## 7. UNKNOWN / NEEDS HUMAN DECISION

1. **Telephony Provider Strategy**: Repository contains references to both Exotel (`EXOTEL_*`) and Plivo (`PLIVO_*`). Confirm whether Plivo is the exclusive production telephony provider for NextLite V3.
