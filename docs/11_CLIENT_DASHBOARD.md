# Client Dashboard

## Goals

The client dashboard is for business owners/managers, not engineers.

## Overview

Show:
- AI employee name
- live/offline status
- phone number
- calls handled
- minutes used
- plan/included usage
- appointments/leads where relevant
- recent activity

## Agent page

Show:
- agent name
- role
- current status
- deployment number
- supported business function

## Analytics

Initial metrics:
- total calls
- connected calls
- completed calls
- average duration
- leads
- appointments
- transfers
- usage

Industry-specific metrics can be added later.

## Billing

Show:
- current plan
- subscription status
- payment history
- invoices where available
- renewal/cancellation state

## UX principle

A client should understand what their AI employee is doing without understanding the underlying technology.
